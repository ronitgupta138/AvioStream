# HPC Degradation Dynamics

## 1. Physical Degradation Phenomenon
High Pressure Compressor (HPC) degradation accounts for >60% of total turbofan efficiency loss over time. The primary physical root causes are blade tip clearance widening, leading edge erosion from particulate ingestion, and aerodynamic boundary layer thickening.

## 2. Telemetry Signature
- Elevation in sensor T30 (+2.5% to +4.8%)
- Drop in sensor P30 (-1.8% to -3.2%)
- Compensatory increase in core speed Nc (+1.2%)

## 3. RUL Impact
Accelerates wear linearly for the first 100 cycles, transitioning into exponential fatigue beyond cycle 150.
