# Sensor phi: Fuel Flow Ratio

- **Unit:** pps/psi (pounds per second per psi)
- **Physical Domain:** Fuel metering unit (FMU) feedback
- **Nominal Operating Range:** 520.00 to 523.00
- **Degradation Dynamics:** Increases as specific fuel consumption (SFC) degrades.
- **Failure Modes:** Fuel nozzle coking and fuel actuator hysteresis.
