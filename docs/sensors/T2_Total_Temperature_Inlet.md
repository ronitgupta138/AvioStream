# Sensor T2: Total Temperature at Fan Inlet

- **Unit:** Degrees Rankine (°R)
- **Physical Domain:** Aerodynamic inlet interface
- **Nominal Operating Range:** 518.67 °R to 641.00 °R
- **Degradation Dynamics:** Ambient condition dependent; steady baseline used for regime normalization.
- **Failure Modes:** Inlet temperature probe sensor drift or icing accumulation.
