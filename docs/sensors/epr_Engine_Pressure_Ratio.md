# Sensor EPR: Engine Pressure Ratio (P50 / P2)

- **Unit:** Dimensionless ratio
- **Physical Domain:** Overall engine aerodynamic expansion
- **Nominal Operating Range:** 1.30 to 1.32
- **Degradation Dynamics:** Direct thrust delivery metric for dual-spool turbofans.
- **Failure Modes:** Uncommanded thrust asymmetry and nozzle throat erosion.
