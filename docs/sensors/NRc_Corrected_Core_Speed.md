# Sensor NRc: Corrected Core Speed

- **Unit:** RPM (corrected by theta temperature)
- **Physical Domain:** Normalized high-pressure core rotor
- **Nominal Operating Range:** 8120.00 RPM to 8145.00 RPM
- **Degradation Dynamics:** Core speed drift indicates HPC vane wear.
- **Failure Modes:** Core aerodynamic stall margin degradation.
