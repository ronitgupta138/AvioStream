# Sensor NRf: Corrected Fan Speed

- **Unit:** RPM (corrected by theta temperature)
- **Physical Domain:** Normalized aerodynamic rotor speed
- **Nominal Operating Range:** 2387.50 RPM to 2388.50 RPM
- **Degradation Dynamics:** Stabilized across varying ambient temperature regimes.
- **Failure Modes:** Tachometer electromagnetic sensor noise.
