# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of **AvioStream** seriously. If you discover a security issue or vulnerability, please **do not open a public issue**.

Instead, please send an email with detailed reproduction steps to:  
**ronitgupta138@gmail.com**

### What to Include
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and exploit scenario.

You will receive an initial response within 48 hours acknowledging receipt of your report.
